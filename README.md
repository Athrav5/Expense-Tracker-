# 💰 Expense Tracker using Python

A simple Python-based Expense Tracker that helps users record their daily expenses, organize spending by category, and calculate total expenses.

## 🚀 Features

- Add and record daily expenses
- Store expense details such as date, category, description, and amount
- Display all recorded expenses
- Calculate total expenses
- Simple and beginner-friendly Python implementation

## 🛠️ Technologies Used

- **Python 3**
- Lists and Dictionaries
- Loops and Conditional Statements
- Basic Data Handling

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/Athrav5/Expense-Tracker-.git
   ```

2. Open the project folder:

   ```bash
   cd Expense-Tracker-
   ```

3. Run the Python program:

   ```bash
   python "Expense Tracker.py"
   ```
